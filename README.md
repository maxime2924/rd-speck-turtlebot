# R&D Project : SynSense Speck + TurtleBot3

Projet R&D (M1 AUSIR, Polytech Nice Sophia / I3S, équipe SPARKS), 2026-2027. Encadrant : Jean Martinet.
Objectif : piloter un TurtleBot3 Burger avec la puce neuromorphique SynSense Speck (caméra événementielle).

## Étapes
1. Connecter la Speck au robot et lire ses événements.
2. Suivi simple d'une cible (sortie de la Speck vers cmd_vel).
3. Extension (perception, navigation), à choisir avec l'encadrant.

## Contenu
- docs/setup-robot.md : préparation du TurtleBot3 (Raspberry Pi 4, ROS 1 Noetic)
- docs/setup-speck-wsl.md : Speck sur PC Windows via WSL2
- scripts/ : scripts utilitaires
- journal/ : journal de bord, une entrée par séance
- reports/ : rapports de séance (PDF)
